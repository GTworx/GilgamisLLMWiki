# Genre: Cognitive Science and Attention Mechanisms

**Category**: Cognitive Science, Visual Attention, Memory Architectures & Active Perception
**Last updated**: 2026-11-24

---

## Overview
Investigates the computational, algorithmic, and neurobiological mechanisms underlying human attention, perception, memory load, and decision-making. Encompasses active vision across saccades, cognitive load theory (intrinsic, extraneous, and germane load in schema acquisition), information foraging theory (information scent, patch dynamics), oscillatory neural synchronization for object segregation, temporal discounting in procrastination, and dual-process cognitive control.
