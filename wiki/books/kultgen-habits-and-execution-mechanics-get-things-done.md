## Analytical Overview
### Decoupling Motivation from Execution

In *How to Get Things Done Even When You Don't Feel Like It*, behavioral design writer Colby Kultgen provides a practical framework for overcoming chronic procrastination. The central psychological breakthrough of modern habit science is that **waiting for 'motivation' is a trap**: emotional motivation is a fickle, fleeting neurotransmitter surge, whereas enduring execution depends entirely on environmental architecture and friction reduction.

### Key Behavioral Protocols

Kultgen outlines tactical interventions:
- **The 2-Minute Rule:** Lowering task activation energy so that starting an activity requires negligible willpower.
- **Temptation Bundling:** Pairing demanding cognitive work with immediate sensory rewards.
- **Implementation Intentions:** Pre-determining precise triggers (Time + Location + Specific Action) that eliminate ambiguous executive choice.
- **Friction Engineering:** Adding physical friction to distractions (locking phones in drawers) while removing friction from high-value tasks.

### Cognitive Momentum

The text demonstrates that action precedes motivation: engaging in physical action for mere minutes alters neurochemical state, generating the intrinsic momentum required for sustained deep work.
