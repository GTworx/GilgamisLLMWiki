## Executive Summary

*Blended: Using Disruptive Innovation to Improve Schools* (published by Jossey-Bass / Wiley, 2015, 333 pp., with a Foreword by [[clayton-m-christensen]]) by Clayton Christensen Institute co-founder [[michael-b-horn]] and [[heather-staker]] is the practical design manual translating the disruptive innovation theory of [[disrupting-class-how-disruptive-innovation-will-change-the-way-the-world-learns]] into concrete K–12 school architectures (source: BOOKS/Education_/Blended_ Using Disruptive Innovation to Improve Schools ( PDFDrive ).pdf, pp. 3–9, 21). The authors define **blended learning** rigorously as any formal education program in which a student learns at least in part through online learning—with some element of student control over time, place, path, and/or pace—and at least in part in a supervised brick-and-mortar location away from home, where the modalities along each student's learning path are connected to provide an integrated learning experience (source: BOOKS/Education_/Blended_ Using Disruptive Innovation to Improve Schools ( PDFDrive ).pdf, pp. 9, 31–62).

Horn and Staker establish the canonical four-model taxonomy of blended learning—**Rotation** (Station Rotation, Lab Rotation, Flipped Classroom, Individual Rotation), **Flex**, **A La Carte**, and **Enriched Virtual**—and distinguish **hybrid sustaining models** (Station Rotation, Lab Rotation, Flipped Classroom, which combine the 'best of both worlds' inside traditional classrooms) from **disruptive models** (Individual Rotation, Flex, A La Carte, Enriched Virtual, which replace the batch classroom architecture entirely) (source: BOOKS/Education_/Blended_ Using Disruptive Innovation to Improve Schools ( PDFDrive ).pdf, pp. 9–13, 31–98). Part II provides a seven-step implementation blueprint covering the rally cry, team architecture (functional, lightweight, heavyweight, autonomous), **Jobs-to-Be-Done** student motivation (*'helping me feel successful'* and *'having fun with friends'*), elevating the teacher role, physical/virtual space design, competency-based mastery progression, and deliberate vs. emergent strategy culture (source: BOOKS/Education_/Blended_ Using Disruptive Innovation to Improve Schools ( PDFDrive ).pdf, pp. 10–12, 101–310).

## Key Arguments / Chapter Breakdown

* **Foreword, Introduction & Part 1 (Chapters 1–2): Understanding Blended Learning & The Hybrid Paradox (pp. xv–xxv, 1–98, PDF pp. 21–126)**:
  * *From Factory Batch to Competency-Based Mastery*: Contrasts time-based, variable-learning factory schooling with mastery-based, variable-time student-centered learning (pp. 5–11). Defines the 4 Blended Learning Models (**Rotation**, **Flex**, **A La Carte**, **Enriched Virtual**) via case studies including KIPP Empower, Teach to One, Summit Public Schools, Carpe Diem, and Rocketship Education, and applies **Theory of Hybrids** to distinguish sustaining hybrids from true classroom disruption (source: BOOKS/Education_/Blended_ Using Disruptive Innovation to Improve Schools ( PDFDrive ).pdf, pp. 9–13, 31–98).

* **Part 2A (Chapters 3–5): Mobilizing to Start, Organizing to Innovate & Motivating Students via Jobs-to-Be-Done (pp. 101–168, PDF pp. 129–196)**:
  * *Fulfilling the Student's Job*: Applies Christensen's **Jobs-to-Be-Done** theory to K–12 students, proving that students do not wake up wanting 'higher state test scores'—their core jobs are **feeling successful (daily progress)** and **having fun with friends in a safe community**. Shows why asking students to 'change jobs' fails and how blended software + small-group projects fulfill both jobs (Ch. 5, pp. 146–158) (source: BOOKS/Education_/Blended_ Using Disruptive Innovation to Improve Schools ( PDFDrive ).pdf, pp. 11, 146–168).

* **Part 2B (Chapters 6–10): Elevating Teaching, Physical/Virtual Setup, Competency-Based Progression & Culture (pp. 169–310, PDF pp. 197–330)**:
  * *Re-Engineering the Teacher Role & School Culture*:Applies Frederick Herzberg's two-factor motivation theory (hygiene vs. motivator factors) to teacher job design (Ch. 6, pp. 169–188), evaluates open/modular vs. integrated software architectures (Ch. 7), replaces seat-time Carnegie units with mastery-based progression (Ch. 8), embeds culture as 'automatic operating procedures' (Ch. 9), and balances emergent discovery-driven planning with deliberate execution (Ch. 10) (source: BOOKS/Education_/Blended_ Using Disruptive Innovation to Improve Schools ( PDFDrive ).pdf, pp. 11–12, 169–310).
